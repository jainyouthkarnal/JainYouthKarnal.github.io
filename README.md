# Jain Youth Karnal — GitHub Pages Website

Static website for **JAIN YOUTH KARNAL / JIN SHASAN PRABHAVNA SANGH Karnal**.

## Files
- `index.html` — website structure/content
- `styles.css` — responsive design
- `script.js` — mobile navigation + year
- `assets/` — supplied Jain Youth Karnal logo and temple/darshan images

## Publish free with GitHub Pages
1. Create a new GitHub repository, for example `jain-youth-karnal`.
2. Upload **all files and folders** from this package to the repository root.
3. In GitHub open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. GitHub will provide the public Pages URL.

## Custom domain later
A custom domain can be connected from **Settings → Pages → Custom domain**.
